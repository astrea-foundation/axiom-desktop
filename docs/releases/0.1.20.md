# Axiom 0.1.20

NEAR AI and Tinfoil chats can call AstreaAI image generation. Image requests
retain the originating chat model for provenance and regeneration while image
attestation, response authentication and settled billing identify AstreaAI.
The default image size remains 1536×1536, with up to five ordered references.

Installed Desktop and standalone CLI register image tools from the secure
provider's loaded local configuration, including automatic bundled discovery.
They no longer require a configuration-file environment variable to expose
`generate` and `view_image`. Remote model metadata cannot enable an unconfigured
image service.

Image requests without a progress listener now complete without waiting for an
unread progress channel. The matching deployed worker fixes image-model adapter
restoration across repeated requests; the hosted browser and gateway include
the corresponding routing, encrypted image storage and recovery fixes.

The 0.1.19 candidate was retained for testing and was never published. This
release includes its fixes and the installed image-tool registration repair.
Signed installer acceptance and public activation are separate release gates
described in the [release procedure](../releasing.md).
