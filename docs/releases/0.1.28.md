# Axiom 0.1.28

New images and edits default to 1536 × 1536 for square output. Regenerating
an older image uses its saved dimensions.

On accounts with the new image queue enabled, Desktop and AxiomCLI can keep
an image request waiting for a GPU for up to ten minutes. **Stop** releases
the request's place. Outside the rollout, image requests use the existing
short wait.
