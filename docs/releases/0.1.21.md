# Axiom 0.1.21

Keeps conversations usable through interrupted image work, unavailable old
attachments and failed automatic summarization. Restore preserves usable text,
omits damaged media details and marks missing tool results as unknown without
executing the tool again. Failed pre-turn summarization retains the complete new
message and uses a bounded partial excerpt of older text, with a notice explaining
the context loss. The saved local journal remains separate from model context.

Image-aware context accounting includes uploads and explicit image views. It uses
the selected model's image allowance and compacts before native request limits
are exceeded. The bounded working image catalog expires older references instead
of permanently preventing more images in that conversation. An expired reference
may need to be attached again for another edit.

Sending, editing and regenerating wait for a fresh native timeline after older
snapshots settle, preventing a completed response from remaining busy. Late title
updates change the sidebar without reopening an unloaded conversation. Switching
to a model without a historical file format keeps plain text usable by omitting
the incompatible old file from model context.

Right-click images in the chat or enlarged viewer to copy the full image to the
system clipboard. Generated image captions identify AstreaAI. Model tag filters
put Uncensored first. Retired Chutes integration and packaging are removed;
AstreaAI on Verda remains the installed image service.

macOS restores native-session credentials with one password read and updates the
existing Keychain item by reference. Disposable background ACP probes can refuse
Keychain dialogs, while normal foreground sign-in keeps the OS authorization flow.

The bundled AstreaAI configuration requires policy sequence 22 or newer and is
qualified against generation 15 with chat, image, tools and vision capabilities.
Fresh hardware/workload verification, provider E2EE and authenticated completion
remain required. The local database schema remains unchanged.

Updates the bundled SQLite database engine and MCP SDK to patched versions,
covering the dependency advisories identified during release qualification.

Signed installer acceptance and public activation follow the
[release procedure](../releasing.md). Checksums and the signed installer inventory
accompany the published Desktop and standalone CLI packages.
