# Axiom 0.1.8

- Desktop and TUI begin provider verification while composing a message, reusing
  valid verification and avoiding duplicate requests while verification is running.
- Desktop's account menu stays open while a response streams.
- Currency amounts remain literal in chat Markdown instead of being mistaken for
  inline math.
- Desktop shows the native sign-in failure reason, including connection errors.

macOS and Windows use combined installers for both supported processor types.
Desktop includes AxiomCLI; standalone CLI installers include the local proxy.
Existing update-signing keys and public download URLs remain unchanged.

See [installation](../installing-desktop.md) for packages and
[release acceptance](../validation.md) for qualification requirements.
