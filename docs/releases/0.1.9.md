# Axiom 0.1.9

- Tinfoil reasoning traces, including DeepSeek V4.1 Flash, now reach the existing
  reasoning display. The native client accepts both `reasoning` and
  `reasoning_content` in streaming and completed responses, without duplicating
  traces when both fields are present.
- Empty traces remain valid. Reasoning stays separate from the answer and is
  subject to the existing size limits and authenticated completion checks.

The payment service now requires 3 confirmations for new deposits. Desktop and
TUI read that requirement from the server, so the deposit display also updates
in older clients; this service change does not require installing 0.1.9.

See [installation](../installing-desktop.md) for packages and
[release acceptance](../validation.md) for qualification requirements.
