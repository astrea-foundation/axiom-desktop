# Axiom 0.1.24

Retry and Continue resume an interrupted response through an internal instruction.
The conversation shows no added continuation message, and the current draft and
attachments stay available. Completed work remains in model history.

The native agent no longer rejects consecutive identical tool calls. Normal tool
permissions, account boundaries, cancellation and provider response verification
remain enforced.

Image capacity errors identify a busy service. The coordinated Platform release
admits concurrent image reservations within the existing capacity and lets the
worker serialize image execution through its bounded queue.

Desktop and bundled AxiomCLI use the same version. A manually distributed Apple
Silicon test package does not activate the public update feed or establish
acceptance on Intel Macs, Windows or Linux. Signing, notarization and publication
follow the [release procedure](../releasing.md).
