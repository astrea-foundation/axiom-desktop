# Axiom 0.1.18

Restores NEAR AI and Tinfoil in the model picker when the installed AstreaAI
configuration is present. Version 0.1.17 returned the locally pinned AstreaAI
offering before fetching the existing provider catalog. Discovery now combines
the validated remote offerings with the installed AstreaAI offering.

Each provider retains its own attestation, E2EE and response authentication
checks. An unavailable remote catalog still permits discovery of locally pinned
AstreaAI, with fresh worker admission required before inference. Cancellation
continues to stop discovery without returning a cached or local success.

Regression checks exercise a combined NEAR/Tinfoil/AstreaAI catalog and an
unavailable catalog with cancellation. Isolated production source qualification
loaded four NEAR offerings, seven Tinfoil offerings and AstreaAI, and completed
an encrypted synthetic request through each provider. Signed-package acceptance
remains part of the release procedure.
