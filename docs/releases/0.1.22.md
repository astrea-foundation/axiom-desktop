# Axiom 0.1.22

Interrupted generations can recover within a bounded retry budget when the
provider supplies the evidence needed to authorize another attempt. Browser
connections can reattach to the same running gateway execution. Partial answers
remain available through Show partial answer, with Retry and Continue controls
where supported. Invalid response authentication remains terminal, and incomplete
display text is excluded from restored model context.

NEAR AI verification supports gateways that return several environments sharing
the selected recipient key. Every selected-key environment must pass the complete
hardware, model, nonce and TLS checks. The account relay keeps the negotiated
attestation contract bound to the worker lease through inference dispatch.

Billing screens accept subscription summaries and balances with active request
holds. Failed payment preparation can recover without permanently blocking
inference. Subscription controls, saved-card setup, credit reconciliation and
billing refresh behavior include the coordinated account-service fixes.

The account website separates Profile, Inbox, Balance and Subscriptions. Desktop
account settings use a more compact identity layout. Factory reset relaunches
the complete application and avoids waiting for draft writes from an unready
renderer.

AstreaAI reserves an input-byte allowance sized to the encrypted request instead
of requesting the global maximum for small messages. The coordinated worker and
account-service release supports the 2048-square image profile. Bundled clients
require signed policy sequence 23 or newer; fresh local hardware and workload
verification, provider encryption and authenticated completion remain required.

Desktop and standalone AxiomCLI share the same product version. Signed installer
acceptance and update-feed publication follow the [release procedure](../releasing.md).
