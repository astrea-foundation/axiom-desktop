# Axiom 0.1.13

This release adds local MCP connections and per-thread tool selection, crypto
top-ups, and the shared chat presentation used by Desktop and encrypted web chat.
It fixes Windows update handoff and authenticates Tinfoil stream completion before
reporting success. Saved web chats use the separate encryption password and
recovery flow; account passwords and credentials are never provider keys.

The release includes the current implementations of local-only historical
commits `3223e800329d0ab3509ac7a6dc72d389962078ed` (literal currency Markdown)
and `d6f9f3b10637d906477efa7a27fb274c1949ad01` (attestation warmup and account
menu behavior). Their original monorepository history is separate from this
repository; these behaviors already exist in its current shared components and
native security code.

Production publication requires successful validation of the exact release
revision, signed installers and a verified signed update inventory. Remaining
manual operating-system and funded payment checks are tracked in
[release acceptance](../validation.md).
