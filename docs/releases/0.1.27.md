# Axiom 0.1.27

Settings has a new **Chats** page. **Clear all chats…** permanently deletes
every chat for the signed-in account on this computer after a confirmation that
shows how many will be removed. Folders, settings, sign-ins and workspace files
are kept. **Factory reset Axiom…** has moved from the Account page to the Chats
page and works as before.

Pressing Escape while a confirmation dialog is busy no longer closes Settings
behind it.

The selected model now warms up as soon as the composer opens, including on the
welcome screen. Chat and attestation checks are faster on high-latency
connections.

AstreaAI’s Qwen3.8 Uncensored now generates a new thread’s title after its first
reply finishes, so the conversation keeps priority on the worker.
