# Axiom 0.1.15

The first message in a new Desktop conversation now keeps its draft and sends
normally when the native runtime publishes its first account or preferences
event. Genuine reconnects and account changes still pause saved messages for
review and require a fresh Send.

Temporary deposit-service outages no longer hide a successfully loaded credit
balance. Optional deposit work has a five-second deadline, overlapping balance
reads share one request, and automatic monitoring backs off after failures.
Balance read failures show an actionable error and can be retried immediately.

Rate-limited requests that received no reply now show **No reply received**.
Account concurrency errors explain how to free a running request. Authentication
failures retain their warning, and inference is never replayed automatically.

Rustls is updated to 0.23.46 for its latest TLS security fixes.

This release also includes the six-hour crypto invoices, invoice cancellation,
quote refresh and trial-capacity retry guidance described in the unpublished
[0.1.14 candidate](0.1.14.md), together with the features in [0.1.13](0.1.13.md).

Desktop and its bundled AxiomCLI share product version **0.1.15**. Local storage
and provider-E2EE authentication contracts remain compatible. Signed installer
qualification and publication follow the [release procedure](../releasing.md)
and [release acceptance](../validation.md).
