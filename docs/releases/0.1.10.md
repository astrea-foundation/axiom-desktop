# Axiom 0.1.10

Fresh Windows Desktop installations check for a newer signed release on their
first app launch. When available, Axiom downloads, verifies, installs and restarts
before sign-in. Progress, retry and a way to use the installed version remain
available. A remembered attempt prevents restart loops. Existing installations
keep their normal update controls; macOS and Linux behavior is unchanged.

Windows website downloads also offer a small native setup EXE that fetches the
latest verified full installer when run. The complete offline EXE remains
available separately and is the package used for Microsoft Store preparation.
Store listing and certification are separate from publishing a signed release.

See [update architecture](../updates.md) and [release procedure](../releasing.md).
