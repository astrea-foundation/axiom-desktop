# Axiom 0.1.31

- Use Axiom in Japanese. Choose English or Japanese in Settings → Appearance →
  Language. Japanese covers the welcome screen, sidebar, composer, chat
  preparation and settings navigation.
- Axiom starts in your operating system's language when it is supported, and
  remembers an explicit choice.
- Manage billing opens Stripe's current Customer Portal links in Desktop and
  AxiomCLI.
- With Agent enabled, ask the model to save an image from the conversation to a
  local file, or export it for a local tool.
- Image tool guidance matches inline image previews, and a locked dependency is
  updated for RUSTSEC-2026-0592.
