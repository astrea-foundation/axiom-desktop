# Axiom 0.1.25

Qwen3.8 Uncensored works again on Windows systems where the isolated AstreaAI
verifier could not resolve hostnames. Axiom now gives the verifier the Windows
system directory it needs for DNS. It still verifies the workload evidence before
sending a message.

Sent messages show Edit, Regenerate and Copy. Each conversation in the sidebar
has a three-dot menu for Rename and Delete, also accessible by keyboard and
right-click.

The model picker stays inside short windows and embedded chats when its search
field gets focus.

Image tool cards now distinguish a busy image service from a gateway failure.
